<h1 align="center">Liquid Hub</h1>

<p align="center">Liquid Hub is a Roblox Scripting hub for Roblox Executors That currently supports 3 Games.</p>

## Supported Games
- Arsenal
- Fling Things and People
- Find the Needle
- Murder Mystery 2 (Maybe)

## How to use
1. Grab the AutoLoader
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/DuckyCashy/LiquidHub/refs/heads/main/autoloader.lua"))()
```
2. Inject into your Executor (Madium, Solara, Opiumware or whatever you use)
3. Wait for it to load.

## What Each Script do and give you

1. Arsenal Script
    - Aimbot
    - ESP
    - Spinbot
    - Anti-Aim
    - Slient-Aim
    - Orbit
2. Fling things and people Script
    - Anti Functions
    - Shaders
    - Slient-Aim
    - ESP
    - Blobman Kick
    - Character Configs
    - World Configs
    - And way way more.
3. Find the Needle Script
    - Highlights the Needle
    - Nothing else.
4. Liquified IY (Universal)
   - Everything that IY has.
   - +Extra Functions
